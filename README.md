# StackVM

A stack-based virtual machine written in C++. Bytecode is assembled from a small text
format and executed on a stack machine with its own heap and garbage collector, plus a
disassembler and a stepping debugger for looking at what's actually running. Windows
only, built with MinGW-w64 through a plain Makefile.
